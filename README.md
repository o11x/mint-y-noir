# mint-y-noir

Mint-Y-Noir  - A Linux Mint Theme Mod (Mint-Y-Dark spin)

## Features

- dark, neutral color windows (graphics work friendly)
- better spacing for those using font scaling
- consistent corner radius across the UI
- coder-friendly accent colors
- it is a mint-y-dark mod, from its original tree (kept everything, modified values only) 

## Install

- for system-wide theme copy to /usr/share/themes (so root apps will be themed too)
